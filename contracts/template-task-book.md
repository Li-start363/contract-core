# 模板:任务书(派单/委托任务专用外壳)

> 与 `contract-core.md` 拼用。目的:像"教孩子读书"一样写清意图,让受托方不用猜。

【任务书】
- 意图:为什么做这件事(背景一句话)
- 方向:往哪个方向找/做,不许碰什么(边界)
- 找什么算数:交付判据(什么算完成,可核对;数字/清单/结构)
- 验收:逐条判据(判据模糊按最严解释)
- 失败信号:什么出现说明路线错了,该停
- 降级预案:做不到全量时,允许收窄到什么(并须重新写"一句话增量")

交付物:【格式/字数/文件数】。不加戏:不改方案/范围/选型;工程护栏(输入校验/错误处理/边界防御)是及格线必做,清单外发现的边界在收尾报备。
