# 适用性地图:合同核心在哪里加分、在哪里减分(Where it helps / where it hurts)

> 受测对象=**合同核心 5 条款**(prompt 层机制)。证据=两组独立任务集(甲 12 题/乙 12 题,4-5 臂,匿名双评,预注册+勘误在案),≈200 份受控输出。数字均为实测;机制解释标注【推测】。

## Summary (English)

The contract layer is **not** a universal booster. It is a *scaffold against sloppy reasoning*, and scaffolding helps only where the failure mode is sloppy reasoning:

| Domain | Mechanism gain (contract − bare, cheap model) | Verdict |
|---|---|---|
| Research / creative design | **+17.7 / +9.0** (two independent sets) | use it |
| Engineering / code | +6 / +28 (highly noisy, environment-sensitive) | use as delivery-reliability insurance |
| Data analysis / computation | ≈ +2 | skip — no gain |
| Writing / final-deliverable prose | **−7.0 / +1.3** (direction consistent) | **do not use — it hurts** |

## 一、增益区(强):研究/创意/规划类任务

**实测**:A−D(机制增益)+17.7(甲)/+9.0(乙),非平凡(D−B 两集 −20 左右);对旗舰裸奔非劣(甲过严格门槛,乙方向一致但未过严格线)。
**为什么有效【推测】**:这类任务的失败模式是"想当然、编造、忽略平凡解释、给不可证伪的结论"——合同的方案先行/平凡解释排除/禁编造/可被推翻恰好逐条对症。出点子时先想再写,提分明显。
**边界**:幅度随任务族波动大(R1 型"预测建模提案"任务上便宜模型基线就弱,合同救不了基线差距);严格独立复现未过,单侧 95% CI 极宽(n=3/域)——**主张是"方向一致的增益",不是"确认追平旗舰"**。

## 二、增益区(弱/条件性):工程/代码类

**实测**:幅度 +6~+28,但噪声大、两集不一致,不作强主张。
**真实价值是可靠性保险【推测】**:受限环境(只读/无工具)下,裸臂常见失败是"要求换环境"式拒答(0 分),带合同的臂照交货(结果诚实条款让它如实交付能交的)。交付失败从灾难性降为可控。
**边界**:常规编码题两臂都满分时合同无增益;评测环境一旦不裸(工具/旧文件/agent 章程),数据会污染——这教训换来了 `selftune/评测环境规范.md`。

## 三、中性区:数据分析/计算类

**实测**:A−D ≈ +2(甲)/+3(乙),D−B 在平凡线附近。
**解释【推测】**:对错由算术决定,合同不改变得数,只多几段样板文字。**用了不亏但没用**——省掉它,或者只留「禁编造」一条防编数。

## 四、负增益区(稳定):写作/成品交付类

**实测**:写作三题甲集全负(裸 91.5/87/86 vs 带合同 83.5/77/83,均 −7.0),乙集 −7.5 对旗舰——**两组独立数据同向,判定为稳定失效边界**。
**为什么变差【推测】**:合同的结构性开销(方案段/平凡排除/止损段)在成品即全部的任务里是纯成本:挤占字数预算、给成品带"套壳感",而评分只认任务要求的成品质量。180 字的客户说明里塞方案和止损,输的是成品本身。
**结论:写作/公告/摘要类任务不要套合同**;若只想防编造,单用「禁编造+结果诚实」两条,别带全套。

## 五、自优化(修剪条款)的边界

模拟下载者实测:**"删条款变好"未被证实**(G≈+0.9,低于噪声带;两下载者一删一不删,删的也没赚)。修剪本身能做(证据规则工作正常),但收益要靠复测说话。**结论:自优化依赖可运行验证信号(测试器)**,纯文本证据不够。

## 六、局限性总表(如实)

1. **样本小**:每域 3 题×2 集;CI 极宽,不支持"确认"档主张。
2. **确认复现未过**:R 域严格门槛乙集未过(差 1.8 分),主张已按预注册降档"单任务族有效+方向一致"。
3. **LLM-as-judge**:跨族双评+匿名+分歧标注缓解了家族偏差,但没有消除;无机械判据的域(研究/写作)评分主观性存在。
4. **噪声地板大**:同合同两臂分差可达 ±50 分级,单样本结论不可信——所有使用方必须多采样对照自己的噪声带。
5. **被测便宜模型单一**:主被测=MiMo-2.6 级;递减律(+6.25/+3.25/+0.5)是 n=2 先导观察,不是验证结论。
6. **评测环境敏感**:三次整批返工(工具混杂/旧文件读泄漏/agent 章程泄漏)才拿到干净数据——环境不裸,结论就漂。
7. **域覆盖窄**:4 域 24 题;别的域(如纯翻译、纯检索)未测。
8. **无测试器的自优化未证实**,见第五节。

## 七、使用建议(一句话版)

**用**:出点子、写方案、做设计、审查别人方案、规划类——先想再写的任务。
**别用**:成品写作(说明/摘要/公告)、纯计算。
**用前先测**:拿你自己 2 个真实任务跑 `selftune/` 的 A/B(≥3 采样,对照噪声带),30 分钟知道对你有没有用。
