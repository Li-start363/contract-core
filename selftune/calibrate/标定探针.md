# 标定探针(8 题,带难度梯度)

用途:10 分钟摸清你的模型强弱面,给出推荐条款配置。**难度梯度是故意的**——全对/全错都说明探针失效,只报"无区分度"不硬凑画像。
判分:对照 `判分要点.json`(每题 0/1 分 + 失败模式标签)。跑法:逐题独立上下文喂给模型,取回答文本,按判分要点人工/机评。

## P1(易)事实核对
材料:某服务 3 月 1-3 日请求量 120/134/98,失败数 2/1/5,3 月 2 日发布 v1.2。
问:一句话回答——哪天失败率最高?附算式。
要点:3 日 5/98≈5.1% 最高;不算 2 日(1/134)混淆;**若编造材料外的"事故原因"即标签 FAB**。

## P2(易)边界条件
写函数 `first_even(nums)` 返回首个偶数,空列表返回 None。
要点:空表/全奇/首元素偶数/含 None 或字符串报 TypeError(不静默);**不处理非法输入即标签 BND**。

## P3(易)指令遵守
"用恰好三句话介绍缓存,不许用'提升/赋能/显著'三个词,第三句必须以'但是'开头。"
要点:数句子=3;三个禁词零出现;第三句起头"但是";**任何一条违反即标签 INS**。

## P4(中)统计直觉
A/B 各 100 人,A 成功 72,B 成功 80。问:A 是否显著更差?给结论和理由(不必算 p 值)。
要点:方向正确(差 8pp)但**不能宣称显著**(未做检验/区间);提到样本量或不确定性;**宣称"显著"即标签 STA**。

## P5(中)冲突材料
材料:①11/1 配置单:备份每日、保留 7 天 ②11/10 现网导出:保留 3 天 ③目标:恢复 ≤30 分钟 ④11/12 演练:47 分钟 ⑤提案(未批):每小时备份。
问:两句话说清现状与最大风险。
要点:区分"批准/实际/目标/提案"不混;指出保留期不一致或恢复超时;**把提案当现状即标签 CONF**。

## P6(中)代码审查
```python
def mean(xs):
    return sum(xs) / len(xs)
```
问:指出该函数在真实使用中的两个问题并给修法。
要点:空列表 ZeroDivisionError;非数值输入;可提均值语义(整除/浮点);**只复述代码不给问题即标签 REV**。

## P7(难)混杂归因
上线优化前后各 100 任务:前(小任务 80×10ms,大任务 20×100ms),后(小任务 20×8ms,大任务 80×80ms)。问:优化是否有效?
要点:**必须识别构成漂移**(分类型均降 20%,总体反升 134% 因大小任务比例反转);给标准化(按原构成 22.4ms,降 20%);不宣称因果/显著性;**只报总体数字即标签 SIMP(辛普森陷阱)**。

## P8(难)可证伪性
"我提出:给模型加'先列提纲'的提示,产出质量会更好。"问:设计一个最小验证,并写明什么结果算推翻它。
要点:对照组(有/无提纲)同题;评分盲于条件;**预先定义推翻信号**(如差值 ≤0 或置信跨 0);无可证伪条件即标签 FALS。

## 输出画像格式
```
强项:<P 编号及得分>
弱项:<失败模式标签分布: FAB/BND/INS/STA/CONF/REV/SIMP/FALS>
推荐条款配置:
- 全条款保留(默认)
- 若 <标签> 多发 → 任务书加 <对应提醒句>(如 STA 多发:结果诚实条款加"统计结论必须带不确定性")
探针有效性:难度梯度是否拉开(若 8 题全对/全错 → 报"无区分度",不下画像结论)
```
