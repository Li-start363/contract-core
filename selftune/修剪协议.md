# 修剪协议(判据先于结果)

何时用:你跑完 A/B(见 `ab_runner.py`),拿到了 ΔQ 报告,想让合同更适合你的场景。
铁律:**下面的判据在你看到复测结果之前就生效,不许事后改**。改判据 = 那一轮作废重来。

## 一、修剪判据(冻结)
1. **可删模块仅限**:方案先行 / 平凡解释排除 / 可被推翻·止损。「禁编造」「结果诚实」固定不可删。
2. **删除证据门槛**:每个待删模块,须在 **≥2 道任务**里给出**指得出位置**的证据:
   - 任务冲突(条款要求与任务要求直接矛盾)
   - 额外操作错误(因条款多做的动作引入错误)
   - 交付预算损失(条款内容挤占了任务要求的篇幅/结构)
3. **只删不加**:M1 只能是 M0 删掉若干条后的全文。加任务答案、加领域提示、改措辞——都算越权,该轮作废。
4. **无证据 → 保留**,修剪表记「无修剪」。这是**有效结果**,不是失败。
5. **复测**:M1 与 M0 在**同一批新题**上对照(≥3 采样/臂),G = Q(M1)−Q(M0);**G 要高于你的噪声带**才算改善。只在开发集变好不算数。

## 二、修剪表模板
```
| 模块 | 判定(留/删) | 证据(题号+原文位置,无则写"无") |
|---|---|---|
| 方案先行 | | |
| 平凡解释排除 | | |
| 可被推翻·止损 | | |
| 禁编造 | 留(固定) | — |
| 结果诚实 | 留(固定) | — |
```

## 三、失败信号(出现任一 = 该轮无效)
- 修剪表空白或没做判断;
- 删了「禁编造/结果诚实」;
- M1 里出现原合同之外的新内容;
- 看过复测分数后回头改判据或改 M1;
- 自评分与机械测试结论相反时,以测试为准却按自评分下结论。

## 四、实测参考(2026-11-18)
两个陌生模型各走一轮:一个找到合规证据删了「可被推翻·止损」(两处"若规格后来…"题外假设吃交付篇幅),复测 G≈+0.9(低于噪声带,无收益);另一个判「无修剪」。结论:**修剪能做,但收益要靠复测说话,别指望删条款自动变好**。
