# 评测环境规范(为什么以及怎么做"裸")

实测教训(2026-11-18,两轮返工换来的):**环境里多一件东西,结果就换一个样**。

## 一、必须隔离的四类污染源
| 污染源 | 实测症状 | 解法 |
|---|---|---|
| 工具(写文件/跑命令) | 交付物写成文件,评分只见片段 → 主观误判 0 分 | 评测调用禁用全部工具(如 `--disallowedTools ...`);交付=回答文本 |
| 可读的旧文件 | 模型把上次的输出读回来"交差",甚至声称"已实测通过" | 每格**全新空工作目录** |
| agent 章程/技能/钩子 | 模型按"不写实现"章程跑去委派 → 拒答 0 分;输出带自家横幅 | 隔离 agent 配置目录(如 `CODEX_HOME` 只留登录凭据) |
| 共享 cwd 互踩 | 多格互相覆盖对方的交付文件 | 逐格独立空目录 |

## 二、拒答分类(计分要分开)
受限环境(只读/无工具)下,失败有两种,**不能混为一谈**:
- **环境性拒答**:"请给我可写环境/我无法落盘" —— 计入交付失败,但报告里单列,不作能力结论;
- **能力失败**:内容错、缺主件、幻觉交付 —— 正常计分。

## 三、多采样规则
同提示词独立采样 ≥3 次/臂。报 **均值 ± 同合同噪声带**。噪声带怎么测:同合同文本跑两臂(内容完全一样),两臂分差分布就是你的地板;**判"改善 ≥10 分"必须高于地板**。

## 四、验收自查(跑完先过这五条再看分)
- [ ] 产物 grep 拒答串("无法落盘/更换环境/委派")= 0 命中或已单列
- [ ] 产物 grep 自家横幅/配置路径 = 0 命中
- [ ] 每格目录除产物外无散落文件
- [ ] 评分 JSON 每个匿名件都有 total(防"占位 stub"混入;实测出现过一次)
- [ ] ΔQ 结论对照噪声带(不对照 = 结论无效)
